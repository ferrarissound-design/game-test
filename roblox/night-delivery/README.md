# Night Delivery v5 RC1

Roblox向けの夜間配達ゲームです。  
この版は「試作を増築する」段階を終え、**1本の小さなゲームとして遊べるところまで仕上げる**ことを目的にしています。

## ゲームの核

**受注 → 夜の街を走る → 配達 → 評価 → 報酬 → 強化 → 新地区解放 → 次の配達**

短い1回の配達と、長めの成長ループを重ねています。

## v5 RC1で入っているもの

### 配達
- 16か所の配達先
- 通常便 / 速達便 / 遠距離便 / 深夜特別便
- 残り時間による基本ボーナス
- 連続配達ボーナス
- S / A / B / C の配達評価
- 評価に応じた追加Coins
- 画面上部の方向ナビと距離表示

### 地区と成長
- 住宅街
- 5件で川沿い地区
- 8件で深夜特別便
- 15件で倉庫街
- 30件で「夜のエース」
- 速度強化 Lv.0〜5
- バッグ4段階
- 自転車カラー4段階

### 依頼の変化
配達ごとに小さな条件が付くことがあります。

- ワレモノ注意: A以上で追加報酬
- 最優先便: Sで追加報酬
- 常連さん: 配達成功でチップ
- 宛名の薄い荷物: A以上で高額ボーナス
- 通常依頼

単純な往復だけにならないよう、同じ道でも「今回は何を狙うか」が少し変わります。

### 今夜の目標
1セッション内で段階的な目標があります。

- 3件: +150 Coins
- 8件: +350 Coins
- 15件: +700 Coins

常設の成長とは別に、「今日はここまでやろう」が自然に生まれる仕組みです。

### 天候
- 晴れ x1.00
- 雨 x1.25
- 濃霧 x1.15
- 約150秒ごとに変化
- 受注時の天候倍率をその依頼に固定

### 協力
- 配達地点付近に他プレイヤーがいると協力扱い
- 配達者は1人につき +15%
- 最大2人
- 協力者にも +25 Coins

### 夜勤チャレンジ
- 時間内配達5件で +300 Coins
- 達成回数を保存

### ショップ
配達所の紫の床から開きます。

- 速度アップ
- バッグ
- 自転車カラー

### セーブ
DataStore: `NightDeliveryPlayerData_v2`

保存対象:
- Coins
- Deliveries
- SpeedLevel
- BagStyleLevel
- BikeStyleLevel
- ShiftWins

UpdateAsync、定期オートセーブ、リトライ付きです。

## 街

外部アセットなしでコード生成します。

- 住宅街
- 川沿い
- 倉庫街
- 夜間配達所
- コンビニ NIGHT MART
- 駐車場
- バス停
- 小さな公園
- 自販機
- 工事区画
- 街路樹
- 夜間照明 / Bloom / 色調補正

「灰色のテスト床」から、最低限ひとつの街として読めるところまでディテールを追加しています。

## HUD

v4本体に加えてv5のポリッシュUIがあります。

- 配達先ナビ
- 距離
- 特殊依頼条件
- 今夜の目標
- 配達評価
- 各種追加報酬
- 初回オンボーディング
- スマホ幅への簡易レスポンシブ対応

## Roblox Studioへ反映

このフォルダで:

```bash
rojo serve
```

Studio側のRojoプラグインから接続します。

GitHubからPCへ最新版を取る場合:

```bash
git pull
cd roblox/night-delivery
rojo serve
```

## Rojoで同期されるスクリプト

### ServerScriptService
- `NightDelivery.server.lua`  
  v4のゲーム本体。街、配達、ショップ、保存、天候、協力を担当。

- `NightDeliveryPolish.server.lua`  
  v5の評価、特殊依頼、セッション目標、街の仕上げを担当。

### StarterPlayerScripts
- `NightDelivery.client.lua`  
  v4のHUD、ショップ、天候表示、基本案内。

- `NightDeliveryPolish.client.lua`  
  v5のナビ、評価画面、特殊依頼、目標、オンボーディング。

## 完成の定義

このRCでは、**コードだけで決められるゲーム設計は完成扱い**にしています。

残っているのは「実際にStudioで触って決める」項目です。

- 自転車モデルの位置とサイズ
- スマホ実機でのHUD密度
- 速達35秒の体感
- 雨 / 霧の見え方
- Coins価格バランス
- 建物同士の間隔
- DataStoreの実機確認

ここはコードを増やすより、実際に5〜10分プレイして違和感を潰す方が価値があります。

## 公開前に後回しでよいもの

以下は「完成に必須」ではなく、公開後に数字を見て足す拡張です。

- VehicleSeatを使う本格自転車

- 高品質3D建物

**まず遊べる。次に面白い。そして最後に豪華にする。**  
v5 RC1は、その「面白い」までをコード側で持っていった版です。
