# 静かな夜間配達 / Night Delivery v2

Roblox向けの「小さく遊べる」配達ゲーム試作です。

## v2でできること

- 夜の小さな街をスクリプトで自動生成
- 8軒の配達先
- 配達所で仕事を受注
- 配達先を黄色いハイライトとマーカーで表示
- 3種類の仕事
  - 通常便
  - 速達便
  - 遠距離便
- 時間ボーナス
- 時間内配達の連続ボーナス
- Coins
- 配達回数
- 配達中は荷物を背負う
- 自転車モードで移動速度アップ
- Coinsを使った速度強化 Lv.0〜5
- Coins / 配達回数 / 速度Lv.のDataStore保存
- PC / モバイル共通のProximityPrompt
- スマホでも見やすい簡易HUD

## 基本ループ

1. 夜間配達所で「配達を受ける」
2. 通常便 / 速達便 / 遠距離便のどれかが選ばれる
3. 黄色く光る家へ移動
4. 家の前で「配達する」
5. Coinsと配達回数を獲得
6. Coinsで速度を強化
7. 次の配達へ

時間内に連続して配達すると、連続ボーナスが少しずつ増えます。

## 配達所の3つの床

- 黄色: 配達を受ける
- 青: 自転車モードのON / OFF
- 紫: Coinsを使って速度強化

自転車モードは、現時点では「物理的な自転車」ではなく高速移動モードです。
まずゲームループとテンポを検証するための仮実装です。

## Roblox Studioへ入れる方法

### 方法A: Rojo

このフォルダで:

```bash
rojo serve
```

Roblox Studio側でRojoプラグインを接続します。

### 方法B: 手動

1. `src/ServerScriptService/NightDelivery.server.lua` の内容を `ServerScriptService` の Script に貼る
2. `src/StarterPlayer/StarterPlayerScripts/NightDelivery.client.lua` の内容を `StarterPlayer > StarterPlayerScripts` の LocalScript に貼る
3. Play

空のBaseplateでOKです。街・配達所・家はサーバースクリプトが自動生成します。

## セーブ機能について

DataStoreを使っています。

Roblox Studio上でセーブを本当に試す場合は、ゲームを一度Publishしたうえで、
Game SettingsのAPI Services設定が必要になる場合があります。

DataStoreが使えない状態でもゲーム本体は動きますが、そのセッションを終了すると進行は保存されません。
