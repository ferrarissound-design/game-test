# Night Delivery — Playable MVP

## 配達先タイプの試験区画

配達先は `NightDelivery.server.lua` の `houseDefinitions` にある `houseType` で設定します。省略時は `Normal` です。現在の試験区画は青い家 (`Construction`) と紫の家 (`HighRise`) で、ほかは通常住宅 (`Normal`) です。種類ごとの形状と追加所要時間は `src/ServerScriptService/NightDeliveryHouseTypes.lua` にあります。既存の `NightDelivery.server.lua` が各区画の `DeliveryPoint` と配達プロンプトを生成し、ジョブ、報酬、進行を管理します。Workspace の `NightDeliveryWorld/Houses` は起動時にコードから生成されます。

工事中住宅は右側を回って裏口へ行く安全ルートと、木箱・足場・柵の上を通る近道があります。高所配達は左側の非常階段から屋上へ向かい、手前の足場から途中の階段へ移る近道があります。既存の配達ルート選択（街灯の道／裏路地の近道）は制限時間と報酬の選択であり、Obby内の物理的な経路はどちらを選んでも自由に選べます。新タイプでは既存の玄関向けランダム配達先イベントと道中イベントを出しません。

Studioで特定の家を繰り返し試す場合、Play中に `workspace.NightDeliveryWorld` の `QAForceHouseName` を `BlueHouse` または `PurpleHouse` にしてから配達所で次の依頼を受けます。空文字に戻すと通常の抽選です。既存の依頼がある間は変更されません。別の住宅・地区を追加するときは `houseDefinitions` の定義と `NightDeliveryHouseTypes` の生成関数を増やしてください。地区名と解放条件は現在の `NightDelivery.server.lua` の `DISTRICT_NAMES` / `isHouseUnlocked` が管理します。

短い配達、街の変化、報酬と強化をひとつの遊べるループにまとめたRoblox向けゲームです。

## ゲームの核

**受注 → 夜の街を走る → 配達 → 評価 → 報酬 → 強化 → 新地区解放 → 次の配達**

短い1回の配達と、長めの成長ループを重ねています。

## 初めて遊ぶとき

1. 黄色い配達所で依頼を受ける。
2. 画面の矢印を追って、家の玄関まで向かう。
3. 玄関の「配達する」を押して報酬を受け取る。

PCはWASDで移動、Eで近くの操作、自転車スタンドではBで切り替えます。スマホは画面のスティックと操作ボタンを使います。制限時間は追加報酬の目安で、時間切れでも配達できます。


## 現在のゲーム内容

### 配達
- 受注後に「街灯の道」か「裏路地の近道」を選択。ルート選択後にタイマー開始
- 街灯の道は時間に余裕、近道は通常 +80 Coins。工事の夜に受注した依頼は +120 Coins。表示額と実際の支払い額を依頼ごとに固定
- 16か所の配達先
- 通常便 / 速達便 / 急ぎ便 / 遠距離便 / 深夜特別便
- 配達先までの距離で制限時間を調整
- 速達便は近場、遠距離便は遠方を優先
- 残り時間による基本ボーナス
- 連続配達ボーナス
- 14%の確率で発生する「ご近所チップ」(+40〜90 Coins)
- S / A / B / C の配達評価
- 評価に応じた追加Coins
- 画面上部の方向ナビと距離表示
- 到着時の2択イベント / 道中ランダムイベント / 途中の追加依頼 / 配達後の次の家選択
- 今夜限定ルールの表示

### 地区と成長
- 住宅街
- 5件で川沿い地区
- 8件で深夜特別便
- 15件で倉庫街
- 30件で「夜のエース」

### 夜のうわさ
配達数が3 / 8 / 15 / 25件に達すると、街にまつわる4つの手がかりが順番に解放されます。最後まで集めると +500 Coins。手がかりの進行はプレイヤーデータに保存されます。
- 速度強化 Lv.0〜5
- バッグ4段階。バッグLv.2で荷物枠2、Lv.3以降で3
- 自転車カラー4段階

### 荷物ごとのルール
受注ごとに荷物の扱いが変わります。荷物ルールはサーバー側で依頼受注時に確定し、ルートを選ぶ前に表示します。単なる評価条件ではなく、移動方法や時間の使い方に影響します。配達評価・ボーナス判定もクライアント通知に依存せずサーバー側で進行します。

| 荷物 | 遊び方の変化 |
|---|---|
| ワレモノ注意 | ジャンプや落下で品質が落ち、評価とボーナスに影響 |
| 冷凍便 | 35秒を超えると品質評価が1段階低下 |
| 大型荷物 | 自転車に乗れない代わりに配達ボーナス |
| 温かい料理 | 30秒以内の配達で追加報酬 |
| 秘密便 / 宛名の薄い荷物 | 遠距離では方向ナビと家のハイライトが弱くなる |
| 高級品 | A評価以上の丁寧な配達で追加報酬 |
| 急ぎ便 | 10〜24秒を目安にした短い制限時間、高めの基本報酬 |

### 配達先イベント
依頼ごとに22%の確率で、到着時に小さな状況イベントが発生します。受取人不在、玄関に犬、正面が工事中の3種類から状況に合わせて届け方を選びます。選択後は玄関脇・安全な置き場所・工事を避けた入口などへ実際に移動し、緑の目印で配達を完了します。サーバー側でも指定地点への到達を確認します。犬イベントでは赤い警戒範囲に入ると犬が吠え、現場判断ボーナスを失います。工事イベントでは選択後に柵が実際の障害物になり、正面突破ではなく開いている側へ回り込む必要があります。選択の報酬は0〜55 Coins。同じ種類のイベントは連続しません。

### 道中ランダムイベント
ルート決定後、配達先まで十分な距離が残っている場合に34%の確率で道中イベントが1回だけ発生します。同じイベントは連続しにくくしています。

- **通行止め**: 正面に実際の障害物が現れ、黄色い迂回ポイントを通るまで配達先へ進めません。解決で +30 Coins。25秒経つと工事車両が移動し、詰まないよう通常ルートへ復帰します。
- **落とし物**: 青い寄り道ポイントが12秒だけ出現。拾えば +60 Coins、そのまま目的地へ進んでもペナルティなし。
- **助け依頼**: 緑の寄り道ポイントが14秒だけ出現。寄れば +45 Coins、急ぐなら無視できます。

通行止めだけは強制イベントなので一時的にナビが迂回地点へ切り替わります。任意イベントでは通常の配達ナビを残し、近くのマーカーを見て寄るかどうかをプレイヤー自身が決めます。イベント地点はサーバー側で地面へ投影し、道路・地面として安全に使える場所が見つからない場合はイベント自体を見送ります。到達と報酬もサーバー側で3D距離を検証します。道中イベント中は追加依頼を重ねず、UIと判断が過密にならないようにしています。目的地へ着いた時点で未処理の任意イベントは正式に見送り扱いにし、玄関イベントと同時表示しません。未回収の街ストーリーがある間も新しい道中ストーリーを重ねません。

### 街の記憶と連鎖イベント
任意の道中イベントを解決すると、その行動が後の配達につながることがあります。

- **落とし物を拾う** → 次の依頼先が持ち主につながり、住人専用の会話と +90 Coins。
- **困っている人を助ける** → 次の依頼先がその人の家族につながり、専用の会話と +70 Coins。
- 続きがある依頼では、配達先イベント・道中イベント・追加依頼・特殊荷物を重ねず、通常便として物語の回収に集中できるようにしています。
- 連鎖を最後まで回収すると **街の信頼 +1**。累計値はDataStoreに保存します。
- 未回収の「続き」も保存されるため、ゲームを閉じても次回プレイで再開できます。連鎖先は住宅街・川沿いの住人から選び、倉庫が「家族の家」になる矛盾を避けます。古い保存データが倉庫を指していた場合も住宅へ再抽選します。

これにより道中イベントはその場だけのボーナスではなく、「さっきの行動が後で誰かの反応として返ってくる」街の記憶になります。

### 追加依頼とバッグ枠
ルートを決めてから8秒後、バッグに空きがあれば38%の確率で近場の追加依頼が届きます。現在地から220 studs以内の家が候補です。35秒以内に受けるか見送り、受けた場合は通常の基本報酬とは別に追加便ボーナス +180 Coins。追加便の荷物はワレモノ / 冷凍 / 大型 / 料理 / 秘密便から抽選されます。追加便の制限時間は配達所からの距離ではなく、前の配達先から次の家までの実距離で計算し、最大35秒です。同じ配達バッチ内ですでに届けた家やバッグに積んである家は再抽選しません。バッグ枠は初期1件、バッグLv.2で2件、Lv.3以降で3件です。追加便を複数受けた場合は、前の配達後に次の行き先を自分で選べます。バッグの見た目解放が容量アップも兼ね、配達中に購入した場合もサーバー側容量へ即時反映します。

### 今夜のルール
夜の条件は240秒ごとに切り替わり、画面右上に表示されます。霧 / 停電 / 夏祭り / チップ増加 / 工事 / 静かな夜の6種類です。視界、街灯、自転車速度、チップ確率、近道報酬を変化させます。霧・停電では遠距離ナビも弱くなります。天候変更と夜ルール変更は別イベントとして通知し、夜ルールが切り替わっただけで「雨になった」などの誤通知は出しません。近道増額・夏祭り+10%・チップ増加など報酬へ影響する夜ルールは依頼受注時に固定し、配達途中で夜ルールが切り替わってもその依頼の支払い条件は変わりません。

### ごくまれな異変
依頼ごとに0.4%の確率で、名前が読めなくなるなどの短い異変が起きます。配達を止めず、短いカード表示だけで街の謎を添えます。

### 住人
16軒に名前のある住人を配置。配達時に短い反応を見せ、同じ家へ再訪すると台詞が変わります。協力者が近くにいる場合は、従来どおり配達者に最大30%の協力加算、協力者に1人+25 Coinsです。

### 今夜の目標
1セッション内で段階的な目標があります。

- 3件: +150 Coins
- 8件: +350 Coins
- 15件: +700 Coins

常設の成長とは別に、「今日はここまでやろう」が自然に生まれる仕組みです。

### 天候
- 晴れ x1.00
- 雨 x1.25
- 濃霧 x1.15
- 約150秒ごとに変化
- 受注時の天候倍率をその依頼に固定
- HUDは「現在の天候」と「この依頼に固定された天候倍率」を分けて表示

### 協力
- 配達地点付近に他プレイヤーがいると協力扱い
- 配達者は1人につき +15%
- 最大2人
- 協力者にも +25 Coins

### 夜勤チャレンジ
- 時間内配達5件で +300 Coins
- 達成回数を保存

### ショップ
配達所の紫の床から開きます。

- 速度アップ
- バッグ
- 自転車カラー

### セーブ
DataStore: `NightDeliveryPlayerData_v2`

保存対象:
- Coins
- Deliveries
- SpeedLevel
- BagStyleLevel
- BikeStyleLevel
- ShiftWins
- RumorClueLevel
- NeighborhoodKindness
- PendingNeighborhoodStory

UpdateAsync、定期オートセーブ、リトライ付きです。同一プレイヤーのオートセーブと退出時セーブは直列化し、古いスナップショットが新しい進行を後から上書きしないようにしています。

## 街

外部アセットなしでコード生成します。フィールドは460×410 studs。建物と主要道路はその中に収まる配置です。

- 住宅街
- 川沿い
- 倉庫街
- 夜間配達所
- コンビニ NIGHT MART
- 駐車場
- バス停
- 小さな公園
- 自販機
- 工事区画
- 街路樹
- 夜間照明 / Bloom / 色調補正

建物、道路、配達所、川沿い、倉庫街がひと続きのフィールドとして読めるように配置しています。

## HUD

- 配達先ナビ
- 距離
- 特殊依頼条件
- 今夜の目標
- 配達評価
- 各種追加報酬
- 初回オンボーディング

## Roblox Studioへ反映

このフォルダで:

```bash
rojo serve
```

Studio側のRojoプラグインから接続します。

GitHubからPCへ最新版を取る場合:

```bash
git pull
cd roblox/night-delivery
rojo serve
```

## Rojoで同期されるスクリプト

### ServerScriptService
- `NightDelivery.server.lua`  
  ゲーム本体。街、配達、ショップ、保存、天候、協力、自転車モデルを担当。

- `NightDeliveryPolish.server.lua`  
  サーバー主導の配達評価、荷物ルール、セッション目標、リスポーン時の荷物監視復旧、街の仕上げを担当。

- `NightDeliveryRules.lua`  
  配達先イベント、夜の条件、発生率と抽選設定を担当。

- `NightDeliveryDiagnostics.server.lua`  
  Studio起動時の読み取り専用QA。家16軒、配達Prompt、主要道路、配達所、自転車・ショップ導線などを検査し、Outputへ `[NightDelivery QA] PASS/FAIL` を表示。

### StarterPlayerScripts
- `NightDelivery.client.lua`  
  v4のHUD、ショップ、天候表示、基本案内。

- `NightDeliveryPolish.client.lua`  
  ナビ、評価画面、特殊依頼、目標、オンボーディング。

- `NightDeliveryBike.client.lua`  
  R6 / R15の乗車姿勢と、移動に合わせたペダル動作。

## Studioで最終確認する項目

ゲームの主要ループと進行要素は実装済みです。実機で次を確認して数値や位置を微調整します。

- 自転車の車輪・姿勢・ペダルの見え方
- 自転車ON→OFFで前傾姿勢が残らないこと、連続リスポーン後も新キャラが正しくアニメーションすること
- スマホ幅でのHUDと操作
- 距離別制限時間の体感
- 雨 / 霧の視認性
- 追加依頼の発生率とバッグ枠の解放ペース
- 配達イベント選択の報酬バランス
- 道中イベントと玄関イベントが重なった時のナビ復帰
- 通行止めの25秒タイムアウトと安全な生成位置
- ワレモノ配達中にリスポーンした後もジャンプ判定が続くこと
- 荷物条件がルート選択より先に表示されること
- 急ぎ便の制限時間と報酬
- Coins価格バランス
- DataStoreの実機確認

Studioで5〜10分プレイし、配達のテンポと操作感を確認して仕上げます。
