# 静かな夜間配達 / Night Delivery v4

Roblox向けの「小さく遊べる」夜間配達ゲーム試作です。
v4では、Roblox Studioで実物を見ながら調整する必要がある部分を除き、コードだけで成立するゲーム要素をかなりまとめて入れています。

## v4でできること

- 夜の街をスクリプトで自動生成
- 16軒の配達先
  - 住宅街 8軒
  - 配達5回で解放される川沿い地区 4軒
  - 配達15回で解放される倉庫街 4軒
- 4種類の仕事
  - 通常便
  - 速達便
  - 遠距離便
  - 深夜特別便
- 深夜特別便は配達8回で解放
- 時間ボーナス
- 時間内配達の連続ボーナス
- 動的な夜の天候
  - 晴れ
  - 雨: 報酬 x1.25
  - 濃霧: 報酬 x1.15
- 天候は約150秒ごとに変化
- 天候は配達受注時に固定され、その依頼の報酬倍率として使われる
- 近くに他プレイヤーがいる状態で配達すると協力ボーナス
- 協力した側にもCoinsを付与
- 時間内配達5件で夜勤ボーナス +300 Coins
- 配達回数でランク表示
  - 新人
  - 配達員
  - ベテラン配達員
  - 夜のエース
- Coins
- 配達回数
- 自転車モード
- 簡易自転車モデル表示
- 速度強化 Lv.0〜5
- ゲーム内ショップUI
- バッグコスメ4段階
- 自転車カラー4段階
- 深夜特別便専用の紫発光荷物
- HUDに以下を表示
  - Coins
  - 配達回数
  - 自転車ON/OFF
  - 次のアンロック
  - 天候と報酬倍率
  - ランク
  - 夜勤進捗
- PC / モバイル共通のProximityPrompt
- Coins / 配達回数 / 速度 / コスメ / 夜勤達成回数をDataStore保存
- v2から同じDataStore名を維持
- UpdateAsyncで保存
- 120秒ごとのオートセーブ
- DataStore読込 / 保存を最大3回リトライ
- RemoteEventの簡易連打抑制
- 参加直後にRemoteEventを取りこぼしても再同期する仕組み

## 基本ループ

1. 黄色い床で配達を受注
2. 指定された家へ移動
3. 家の前で配達
4. Coinsと配達回数を獲得
5. 天候・時間・連続配達・協力で報酬が変化
6. 紫の床からショップを開く
7. 速度やコスメを強化
8. 配達回数で新地区・特別便を解放
9. 夜勤5件達成で追加報酬
10. 次の配達へ

単純な「走って届ける」だけではなく、
**配達 → 稼ぐ → 強化 → 解放 → 条件で稼ぎ方を変える**
ところまでを1つのループにしています。

## アンロック

- 配達 0〜4回: 住宅街
- 配達 5回: 🌉 川沿い地区
- 配達 8回: 🟣 深夜特別便
- 配達 15回: 🏭 倉庫街
- 配達 30回: ランク「夜のエース」

## 天候

サーバー全体で天候が変わります。

### 晴れ
- 通常倍率 x1.00

### 雨
- 報酬 x1.25
- Lightingを暗くし、視界を少し狭める

### 濃霧
- 報酬 x1.15
- FogとAtmosphereを強める

外部アセットなしで、クライアント側に軽量な雨筋オーバーレイと霧オーバーレイを表示します。
本物の3D雨粒ParticleEmitterや雨音は、Studioで見た目を確認した後に追加する想定です。

## 協力ボーナス

配達完了時に別プレイヤーが配達地点の近くにいると協力扱いになります。

- 配達者: 1人につき報酬 +15%
- 最大2人分
- 協力者: +25 Coins

専用パーティーUIを作らなくても、同じ街で一緒に動く意味が生まれる軽量な協力要素です。

## 夜勤チャレンジ

時間内配達を5件達成すると:

- +300 Coins
- 夜勤カウンターが1増える
- 次の夜勤チャレンジは0/5から再開

夜勤途中の進捗はセッション単位です。
夜勤達成回数はDataStoreに保存されます。

## ショップ

配達所の紫の床からUIを開きます。

### 速度
- Lv.0〜5
- Coinsで強化

### バッグ
1. クラシック
2. ブルー
3. ネオン
4. ゴールド

### 自転車カラー
1. スチール
2. レッド
3. ネオン
4. ゴールド

購入判定はサーバー側で行い、ショップから離れた場所からRemoteEventだけを送って購入できないよう距離チェックを入れています。

## 配達所

- 黄色: 配達を受注
- 青: 自転車モードON / OFF
- 紫: ショップ

## Roblox Studioへ入れる方法

### Rojo

このフォルダで:

```bash
rojo serve
```

Roblox Studio側でRojoプラグインを接続します。

### 手動

1. `src/ServerScriptService/NightDelivery.server.lua` を `ServerScriptService` の Scriptへ
2. `src/StarterPlayer/StarterPlayerScripts/NightDelivery.client.lua` を `StarterPlayer > StarterPlayerScripts` のLocalScriptへ
3. Play

空のBaseplateで動作する設計です。

## DataStore

DataStore名:

```
NightDeliveryPlayerData_v2
```

v2 / v3から名前を変えていないため、既存データを引き継げます。

保存対象:

- Coins
- Deliveries
- SpeedLevel
- BagStyleLevel
- BikeStyleLevel
- ShiftWins

Studioで保存を確認する場合はPublishとAPI Services設定が必要になる場合があります。

## Studioで確認したいこと

コード側で詰められる部分はかなり入れたため、ここからは**見て触って決める工程**が中心です。

1. 簡易自転車モデルの位置・大きさ・向き
2. 自転車使用時の歩行アニメーションとの違和感
3. 川沿い地区・倉庫街の道路と家配置
4. 雨・濃霧の見え方
5. スマホでHUDが大きすぎないか
6. ショップUIのボタンサイズ
7. 速達35秒の難易度
8. 5回 / 8回 / 15回のアンロックテンポ
9. Coinsの増え方
10. コスメ価格
11. 協力ボーナスの距離36 studs
12. 実機でDataStore保存・復元
