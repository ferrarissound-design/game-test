# 静かな夜間配達 / Night Delivery v3

Roblox向けの「小さく遊べる」夜間配達ゲーム試作です。

## v3でできること

- 夜の小さな街をスクリプトで自動生成
- 12軒の配達先
  - 最初から遊べる住宅街 8軒
  - 配達5回で解放される川沿い地区 4軒
- 配達所で仕事を受注
- 配達先を黄色いハイライトとマーカーで表示
- 4種類の仕事
  - 通常便
  - 速達便
  - 遠距離便
  - 深夜特別便（配達8回で解放、低確率の高報酬依頼）
- 時間ボーナス
- 時間内配達の連続ボーナス
- Coins
- 配達回数
- 配達中は荷物を背負う
- 深夜特別便は紫に光る専用荷物
- 自転車モードで移動速度アップ
- Coinsを使った速度強化 Lv.0〜5
- Coins / 配達回数 / 速度Lv.のDataStore保存
- PC / モバイル共通のProximityPrompt
- スマホ向けHUD
- HUDに次のアンロックまでの進捗を表示

## 基本ループ

1. 夜間配達所で「配達を受ける」
2. 指定された家へ移動
3. 家の前で「配達する」
4. Coinsと配達回数を獲得
5. Coinsで速度を強化
6. 配達回数を増やして新地区・レア依頼を解放
7. 次の配達へ

時間内に連続して配達すると、連続ボーナスが少しずつ増えます。

## 進行アンロック

- 配達 0〜4回: 住宅街のみ
- 配達 5回: 🌉 川沿い地区が解放
- 配達 8回: 🟣 深夜特別便が解放
- 深夜特別便は解放後も低確率で出現するレア依頼

「あと何件で次が開くか」はHUD下段に表示されます。

## 配達所の3つの床

- 黄色: 配達を受ける
- 青: 自転車モードのON / OFF
- 紫: Coinsを使って速度強化

自転車モードは、現時点では「物理的な自転車」ではなく高速移動モードです。
まずゲームループとテンポを検証するための仮実装です。

## Roblox Studioへ入れる方法

### 方法A: Rojo

このフォルダで:

```bash
rojo serve
```

Roblox Studio側でRojoプラグインを接続します。

### 方法B: 手動

1. `src/ServerScriptService/NightDelivery.server.lua` の内容を `ServerScriptService` の Script に貼る
2. `src/StarterPlayer/StarterPlayerScripts/NightDelivery.client.lua` の内容を `StarterPlayer > StarterPlayerScripts` の LocalScript に貼る
3. Play

空のBaseplateでOKです。街・配達所・家はサーバースクリプトが自動生成します。

## セーブ機能について

DataStoreを使っています。

Roblox Studio上でセーブを本当に試す場合は、ゲームを一度Publishしたうえで、
Game SettingsのAPI Services設定が必要になる場合があります。

DataStoreが使えない状態でもゲーム本体は動きますが、そのセッションを終了すると進行は保存されません。

v3でもDataStore名はv2のまま維持しているため、v2で保存した Coins / 配達回数 / 速度Lv. を引き継げます。

## Studioで優先して確認したいこと

1. 川沿い地区まで道路が自然につながっているか
2. 配達5回までが長すぎないか / 短すぎないか
3. 配達8回で特別便を解放するテンポ
4. 深夜特別便の出現頻度と報酬220 Coinsのバランス
5. 徒歩 / 自転車モードの速度感
6. 速達35秒が厳しすぎないか
7. HUDがスマホで邪魔にならないか
8. 1回配達したあと「もう1回」が自然に出るか
