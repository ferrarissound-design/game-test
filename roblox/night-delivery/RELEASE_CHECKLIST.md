# Night Delivery v5 RC1 - Studio QA

コード側はRC1まで完成。ここからはStudioで「壊れていないか」と「触り心地」を確認する。

## まず確認

1. PCで `git pull`
2. `cd roblox/night-delivery`
3. `rojo serve`
4. StudioでRojo Connect
5. Play

## v5が入った目印

次が見えれば新しいpolish layerまで同期できている。

- 配達所周辺に自販機
- 街に `NIGHT MART`
- バス停と小公園
- 右下に「今夜の目標」
- 配達受注後、画面上部に方向ナビ
- 左下に依頼条件
- 配達完了時に S / A / B / C 評価

## 10分テスト

### 1. 最初の配達
- 黄色い床から受注できる
- 方向ナビが目的地を指す
- 距離が減る
- 家で配達できる
- 評価画面が出る
- Coinsが増える

### 2. 3件まで
- 特殊依頼が時々出る
- 3件達成で「夜の肩慣らし」報酬 +150
- 右下の次目標が8件へ切り替わる

### 3. 5件まで
- 川沿い地区が解放される
- 新しい配達先が選ばれる
- 夜勤5件条件を満たした場合、既存v4の夜勤報酬も動く

### 4. ショップ
- 紫床からショップが開く
- 速度アップ購入
- バッグ購入
- 自転車カラー購入
- Coins不足時に不正購入できない

### 5. 天候
- 晴れ / 雨 / 濃霧が変化する
- HUDの倍率が変わる
- 雨・霧で視認性が極端に悪くない

### 6. スマホ表示
Device Emulatorまたは実機で確認。

- ナビが上部UIと重ならない
- 左下の依頼条件が操作を邪魔しない
- 右下の今夜の目標が大きすぎない
- ショップが押せる
- ProximityPrompt操作ができる

## 調整基準

迷った場合は以下を優先する。

1. 「次に何をすればいいか」が1秒で分かる
2. 配達1回が長すぎない
3. 3件目までに報酬感がある
4. UIがゲーム画面を食いすぎない
5. 見た目より操作感を優先

## 公開判断

以下が全部OKなら、機能追加を止めて公開候補にする。

- 10分プレイして進行不能なし
- PC / スマホで受注・配達・ショップ操作可能
- DataStore保存 / 復元確認
- 3件報酬が二重受取できない
- 配達評価が1回につき1回だけ出る
- Rojo再接続後もv5 UIが二重生成されない

ここを通ったら「さらに機能を足す」より公開して反応を見る。
