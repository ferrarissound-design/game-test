# Night Delivery - Studio QA

GitHub側の静的監査と修正を終えた後に、Roblox Studioで実機挙動だけを確認するためのチェックリストです。

## 0. 同期

1. `git pull`
2. `cd roblox/night-delivery`
3. `rojo serve`
4. StudioでRojo Connect
5. Play
6. Outputで `[NightDelivery QA] PASS` を確認

FAILやWARNが出た場合は、その行をそのままChatGPTへ渡せば原因を追いやすくなります。

### Studio限定: ランダム待ちを飛ばす

Play中に Explorer → `NightDeliveryWorld` → Attributes から次を変更できます。空文字 `""` に戻すと通常抽選です。

- `QAForceDestinationEventId`: `absent` / `dog` / `work`
- `QAForceTravelEventId`: `roadblock` / `lost_item` / `help_request`
- `QAForceModifierId`: `none` / `fragile` / `premium` / `tip` / `mystery` / `frozen` / `oversized` / `hot` / `secret`
- `QAForceWeatherId`: `clear` / `rain` / `fog`
- `QAForceNightConditionId`: `quiet` / `fog` / `blackout` / `festival` / `tip` / `roadwork`

天候と夜ルールは属性を変更した瞬間に反映。玄関・道中・荷物は次に受ける依頼で反映します。これらの強制処理はStudioでのみ有効です。

## 1. まず普通に1配達

- 黄色い配達所で受注
- 荷物条件がルート選択より先に表示される
- 街灯 / 近道を選べる
- ルート決定後にタイマー開始
- ナビ、距離、依頼固定の天候倍率が表示される
- 配達後にCoinsとS/A/B/C評価が各1回だけ出る

## 2. 道中イベント

### 通行止め
- 黄色い迂回地点へナビが切り替わる
- 解決後は家ナビへ戻る
- 放置しても25秒で解除され、進行不能にならない

### 落とし物 / 助け依頼
- 通常の家ナビを維持したまま寄り道マーカーが出る
- 無視して目的地へ着いたら寄り道UIが消える
- 玄関イベントと同時に残らない
- 解決した場合は後の「街の記憶」へつながる

## 3. 玄関イベント

- 不在 / 犬 / 工事が出たら2択できる
- 選択後に緑の地点まで移動して配達
- 犬は赤い範囲へ入るとボーナスを失う
- 工事は正面障害物を回り込める
- 道中イベントの期限切れ通知で緑ナビが壊れない

## 4. 荷物条件

- ワレモノ: ジャンプで品質低下
- ワレモノ中にResetし、復帰後もジャンプ判定が続く
- 大型荷物: 自転車が強制OFFになり再乗車できない
- 冷凍便: 35秒超で評価低下
- 温かい料理: 30秒以内でボーナス
- 秘密便 / 宛名の薄い荷物: 遠距離ナビが弱い

## 5. 追加依頼 / バッグ

バッグLv.2以上で確認。

- 追加依頼のバッグ枠が表示される
- +180 Coinsが基本報酬とは別で表示される
- A宅を届けた後、同じ配達バッチでA宅が再候補にならない
- 複数積んだ場合、次の家を選べる
- 次の家の制限時間が「配達所」ではなく現在地からの距離に合っている
- 各ストップで評価が1回ずつ出る

## 6. 街の記憶

- 落とし物 / 助け依頼の解決後に続きの予告が出る
- 次の対象は住宅で、倉庫にならない
- 専用住人台詞とボーナスが出る
- 街の信頼 +1
- 続きを作った後に退出 → 再参加して続きが残る

## 7. 夜ルール / 天候

- 天候: 晴れ / 雨 / 濃霧
- 夜ルール: 静か / 霧 / 停電 / 夏祭り / チップ / 工事
- 夜ルール変更だけで「雨になった」等の誤通知が出ない
- 霧 / 停電では遠距離ナビが弱くなる
- 工事の夜に受けた近道は表示・支払いとも +120
- 夏祭り / チップの報酬条件は受注後に夜ルールが変わっても維持される
- HUDの「現在天候」と「この依頼の固定倍率」が食い違わない

## 8. 自転車 / 徒歩報酬

- ONで速度と乗車姿勢が変わる
- OFFで前傾姿勢が残らない
- Resetを何度か繰り返しても新キャラの姿勢が正常
- 夏祭り中の自転車速度低下が反映される
- 徒歩で時間内に通常配達すると距離に応じて +20 / +35 / +55 Coins の徒歩手当が出る
- 自転車を使った配達では徒歩手当が出ない
- ルート開始後に自転車をONにしても徒歩手当へ戻せない
- 大型荷物は強制徒歩だが、追加の徒歩手当は出ない
- Dispatch Boardで荷物条件の成功報酬と徒歩手当の候補額が見える

## 9. ショップ / 成長

- 速度強化
- バッグ
- 自転車カラー
- Coins不足では購入不可
- 配達中にバッグを強化した場合、バッグ容量表示もサーバー側も更新される
- 5件で川沿い、8件で特別便、15件で倉庫

## 10. セーブ

- Coins / Deliveries / 強化 / 街の信頼を確認して退出
- 再参加で値が戻る
- 未回収の街ストーリーも戻る
- 退出前後でCoinsが古い値へ巻き戻らない

## スマホ

Device Emulatorまたは実機。

- ナビと上部HUDが重ならない
- ルート選択、玄関イベント、追加依頼をタップできる
- 左下の荷物条件と右下の目標が操作を邪魔しない
- 縦持ちでも重要UIが画面外へ出ない

## 公開候補の最低ライン

- 15〜20分遊んで進行不能なし
- 通常配達 / 道中イベント / 玄関イベント / 追加依頼が連続して動く
- PC / スマホで操作可能
- DataStore保存・復元OK
- 評価・セッション報酬の二重受取なし
- `[NightDelivery QA] PASS`
- Outputに新しい赤エラーなし

ここまで通ったら、新機能追加を再開してよい状態です。
